💧 Hydrosense AI: Smart Building Water Management System

Siemens Climathon Hackathon Project 🏆
An AI-driven analytics platform designed to optimize water consumption and enhance sustainability in smart building ecosystems.

📌 Project Overview

In modern infrastructure, resource optimization is just as critical as financial optimization. Hydrosense AI is a conceptual smart building solution developed for the Siemens Climathon. It leverages data analytics and predictive modeling to monitor, analyze, and optimize real-time water usage.

This project demonstrates my ability to build scalable architectures, integrate data-driven decision-making (AI/ML concepts), and create systems that deliver clear business and environmental value.

🚀 Key Features

Predictive Analytics: Analyzes historical and real-time data to forecast water consumption patterns.

Anomaly Detection: Identifies potential leaks or irregular usage spikes to prevent resource waste.

Real-Time Dashboard: A responsive user interface for facility managers to monitor building metrics seamlessly.

Sustainable Business Logic: Translates raw sensor data into actionable insights for cost reduction and environmental sustainability.

⚙️ Installation & Setup

To run this project locally, follow these steps:

Clone the repository:

git clone https://github.com/esmnrerdn/hydrosense-ai.git


Install dependencies:

cd hydrosense-ai
npm install


Configure Environment Variables:
Create a .env file in the root directory and add the necessary database and API keys.

DATABASE_URL="postgresql://user:password@localhost:5432/hydrosense"


Run the application:

npm run dev
